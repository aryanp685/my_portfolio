# Aryan Patil — Portfolio

My personal portfolio website, built with React, Vite and Tailwind CSS v4.

## Features

- Working contact form - messages land straight in my Gmail inbox
- Real project cards pulled from my GitHub repositories
- Smooth scroll-reveal animations
- Fully responsive, dark themed UI

## Tech Stack

React · Vite · Tailwind CSS v4 · Lucide Icons

## Run Locally

```bash
npm install
npm run dev
```
